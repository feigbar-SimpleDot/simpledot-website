常见问题

关于平台边界与任务运行的高频问题，持续补充。

本平台是为「任务编排」服务的轻量界面（看板 + 对话入口 + 执行员注册），不是 Hermes 的通用 Web 前端。需要更完善的 WebUI 请用 hermes-webui。

会话存档独立于进程存活，执行容器崩溃后可凭存档同会话恢复；失败只标记阻塞、绝不误判成功，重派是主控（main）的显式决策。

严格来说，这不是一个简单的"能不能"的问题。Simple-Dot 依靠多个 Agent 协作来保证长时任务的稳定执行：每个 Agent 都会生成报告，交由主控（main）检查核对——这本身会产生 token 消耗。但它换来的是更少的后期返工，也避免了反复上下文压缩带来的重复澄清，以及上下文超限后不得不重开对话、重新补 prompt 的过程——这些往往才是长时任务里更大、更难避免的 token 开销。因此，我们更建议没有 token 焦虑的用户使用 Simple-Dot：如果你有本地算力，或者有高额度的 coding plan，Simple-Dot 会大大提升你的幸福感。
