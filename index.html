快速开始 / Quick Start

快速开始

项目要求自检命令
Dockerv20+ 且当前用户可执行docker ps
compose 插件docker compose v2docker compose version
模型端点OpenAI 兼容 API，已在 Hermes 配好curl <base_url>/models
Docker v20+compose 插件模型端点

① 拿代码

git clone https://github.com/feigbar-beep/simpledot-agent-studio && cd <repo>

② 填配置（只填带 ★ 的一项即可跑）

cp .env.example .env && vi .env
★ API_SERVER_KEY（生成：openssl rand -hex 32）

③ 一键部署

./deploy/install.sh

④ 验证并打开控制台

./deploy/verify.sh
open http://<host>:8700

加第一个 worker（控制台操作，无需命令行）

  1. 打开控制台 → Worker 管理 → 添加 worker
  2. 填 profile 名（如 coder）与 gateway 地址；模型字段只是请求别名，真实模型由 worker 自己的 Hermes 配置决定
  3. 控制台生成 worker compose 片段 → 按提示在目标机器起容器
  4. 保存后 main 即可向该 profile 下发任务
worker 容器必须设环境变量 HERMES_WRITE_SAFE_ROOT=/share_workspace，否则写不了共享卷。
模型 / 端点是 Hermes 自身的配置，本平台不代管——改模型只改 worker 自己，注册表一字不动。

完整故障排查见部署文档 DEPLOY ↗

各管一段，互不越界

「这里管工作流，那里管 Agent。」

想让 Agent 本身更强，去配 Hermes；想让它们协同干活可管理，用我们。

hermes-webui ↗

本平台是为「任务编排」服务的轻量界面（看板 + 对话入口 + 执行员注册），不是 Hermes 的通用 Web 前端。需要更完善的 WebUI 请用 hermes-webui。
会话存档独立于进程存活，执行容器崩溃后可凭存档同会话恢复；失败只标记阻塞、绝不误判成功，重派是主控（main）的显式决策。

全本地部署：看板、会话、产物都在你自己的 ./data/ 目录，整目录拷走即可迁移。
